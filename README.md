# 🚗 Driving City – Unity 2D Project

## 📌 About the Project
**Driving City** is a 2D car driving game developed using **Unity** and **C#**. The player controls a car and can drive forward, backward, and turn left or right using keyboard controls.

The project focuses on practicing player movement, rotation, keyboard input, and movement boundaries in Unity.

## 🎮 Controls

| Key | Action |
|---|---|
| W / ↑ | Move Forward |
| S / ↓ | Move Backward |
| A / ← | Turn Left |
| D / → | Turn Right |

## ⚙️ Features
- Car movement using keyboard input.
- Forward and backward movement.
- Left and right rotation.
- Support for both WASD and arrow keys.
- Configurable movement and turning speed.
- Movement boundaries to keep the car inside the game area.
- Unity Input System integration.

## 🛠️ Technologies Used
- **Game Engine:** Unity
- **Programming Language:** C#
- **Input Handling:** Unity Input System
- **Version Control:** Git & GitHub

## 📂 Main Script
The `playerCar` script handles the car's movement and rotation.

### Configurable Variables
- `moveSpeed`: Controls the car's movement speed.
- `turnSpeed`: Controls how fast the car rotates.
- `bound`: Defines the movement boundaries of the car.

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open Unity Hub.
3. Select **Add Project** and choose the downloaded folder.
4. Open the project using Unity.
5. Press the Play button to start driving!

## 🎯 Learning Objectives
This project helped me practice:
- Working with Unity's Transform component.
- Handling keyboard input with the Input System.
- Using `Time.deltaTime` for frame-independent movement.
- Applying rotation and translation.
- Using `Mathf.Clamp()` to restrict player movement.
- Organizing C# scripts with `[SerializeField]` and `[Header]`.
